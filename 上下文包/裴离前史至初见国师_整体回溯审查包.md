# 裴离前史至初见国师：整体回溯与路线重审包

> 用途：交给 Kimi K3、GLM-5.3 或 Hy4 Preview 作独立审查，也可单独交给其中任一模型。  
> 性质：审查材料，不是 canon，不授权修改资料库。  
> 审查范围：从裴离的起源、老工匠关系、西域入场、与斯摩奇相遇、主动跨界，一直审查到他第一次见阿克塔尔。  
> 特别要求：不要顺着现有结论做润色。请先判断前提本身是否成立；若前提有问题，可以建议撤回已经批准的内容，但必须说明撤回会影响哪些后续设定。

## 一、本轮为什么重审

此前已经逐步批准了裴离的起源、个人动机、入场因果和跨界后过渡。但继续向“第一次见阿克塔尔”推进时，连续出现了几个明显问题：

1. 情节容易被写成裴离到研究院后立即查资料、听国师讲理论，人物像被送到主题讨论桌前。
2. 为了让裴离留下，临时提出“研究院刚好拥有与老工匠伤势完全对应的手部辅助技术”，用户认为巧合过强，已明确否定。
3. 又提出“裴离查到空白心石记录，由此立刻理解自己是环境与生活共同形成的结果”，用户认为不好。该段只是临时提案，不得当作已批准人物领悟。
4. 原批准路线是“落地后约三章过渡，再由地方报告引来研究院调查人员邀请”；用户随后提出更有行动性的替代方向：斯摩奇低估阿克塔尔对核心的掌控，直接带裴离尝试修复核心，行动失败后两者分开。两条路线目前冲突，新路线尚未批准。
5. 用户怀疑问题不只在最近一段，因此要求同时倒查此前已经决定的裴离起源、动机、相遇和跨界因果，看它们是否与全书主题、人物弧线和长篇节奏真正匹配。

本轮不要继续向后编剧情。先完成整体诊断，再选择“保留、修改或撤回”。

## 二、全书核心主题与人物关系

全书最高层命题是：**当人的思想、感情和决定都有原因，甚至能够被镜子提前推演时，人的选择是否仍有意义，是否仍然属于作出选择的人？**

必须遵守以下主题边界：

- 决定论不能偷换成宿命论。人的判断本身也是因果链的一部分，会真正造成后果。
- 裴离不能靠“镜子无法预测他”证明自由。阿克塔尔最终可以准确推演裴离的拒绝，冲突在于这项拒绝是否仍属于裴离。
- 阿克塔尔不是单纯追求权力。他最初想减少战争、饥饿与可以避免的死亡，后来相信只要掌握并安排形成选择的客观条件，就能让社会和人变得更好。
- 阿克塔尔尊重裴离，因为裴离是空白心石在他直接控制之外成长出来的结果，是其理论最重要的验证对象。他真正渴望的是裴离在充分理解后自愿认可他；强迫或改写出来的认同没有价值。
- 裴离和阿克塔尔不能从一开始就是善恶对立。两人都具有“找到原因并修好痛苦”的愿望，差异必须从具体经历中逐渐形成。
- 斯摩奇最初按使命、能力和用途理解自己与他人。它不是恶意强迫者，但会默认有能力者应当协助修复核心。它的改变必须经过阿月与裴离带来的具体关系和后果。
- 阿克塔尔的秩序确实减少饥饿和灾害，拥有真实成绩与真实支持者；绿洲也必须承担自由、保密和分散协作的真实代价。

## 三、已经批准、但本轮允许倒查的基础

以下内容目前属于已批准设定。审查者不能悄悄改写，但可以指出结构性问题并建议正式撤回。

### 1. 裴离的起源

- 裴离是现世唯一的人偶，不存在前代失败品、批量人偶或人格程序冲突。
- 他的身体由一个架空东方国度的老工匠制造；木为骨、银为筋、灵石为心。
- 心石来自阿克塔尔早年的跨世界实验。阿克塔尔没有写入服从人格，把一块空白心石送往一个在他看来相对安定、较少战争与饥饿的世界，观察环境是否能使它成长为更好的人。
- 阿克塔尔失去了对实验对象的持续观察，不能预知裴离必然存活、成为人或返回碎月国。裴离回来后，他才把结果视为理论的重要验证。

### 2. 老工匠与裴离的个人动机

- 老工匠仍然活着。数年前，一次与裴离、阿克塔尔及核心脉冲均无关的普通工坊事故伤及他的颈背。
- 老工匠意识和语言无损，双手外观完整，但失去精细控制。他已经改为口述指导年轻工匠等方式继续生活，不是停在原地等待解药的任务道具。
- 裴离自己的木骨、银筋和肢体可以更换修补，因此他长期把“恢复原有功能”理解为帮助与爱最直接的形式。他多年制作支架、调整工具、记录活动幅度，仍未成功。
- 裴离接受西域任务的核心个人原因，是寻找心石与人造身体的源头技术，尝试恢复老工匠双手的精细控制。
- 当前真正难以接受“不能恢复原状”的主要是裴离。后续他必须从老工匠本人及其他普通人的生活中明白：知道原因和拥有技术，不自动产生替别人规定何谓完整的权利。

### 3. 西域入场与相遇因果

- 阿克塔尔强行启动控制核心，旧镜路脉冲同时触发斯摩奇的残余自检，并使裴离世界的西域固定端点短暂出现异象。
- 异象消息传回东方后，皇帝派使团调查；因遗迹光纹与裴离心石同源，裴离被纳入使团。皇帝的更深层目的仍未决定。
- 初次异象只使遗迹短暂复苏，没有打开稳定通道；斯摩奇此时不知道裴离存在，也没有追踪、等待或召回他。
- 裴离亲临遗迹并以心石连接固定端点后，旧路才形成实时回路。斯摩奇由此第一次发现端点上存在同源生命，并循已经打开的旧路跨界。
- 西域遗迹只是损坏的固定端点，不保存完整制造技术。斯摩奇只能确认裴离心石的来源、相关记录和可读取记录的核心位于碎月国，不能保证那里一定有治疗方法，也不能保证顺利返程。
- 裴离明知风险仍主动跨界，因为留在原世界意味着安全，却无法推进多年目标。此时他不是为了拯救碎月国，不是继续执行皇命，也尚未充分信任斯摩奇。

### 4. 当前已批准的跨界后过渡（可能被新方案替换）

- 两者落在远离王城的对应固定端点遗址。该地只是古代镜路出口，不是已撤回的“旧镜站”，没有唯一关键残片，也不与圣火祠、绿洲或既有人物据点合并。
- 斯摩奇因跨界耗力，暂时不能重新打开返程通道。
- 约三章的同行原计划承担三项功能：裴离亲眼看到道路、水井、驿站和粮仓协作的真实成绩；尝试处理斯摩奇的外部损伤但无法恢复其根本功能；初次感到斯摩奇按能力和用途理解自己。
- 当前批准的抵达方式是：地方人员按普通流程上报端点异动，研究院调查人员在路上找到两者并发出邀请，裴离为查记录自愿接受。
- 语言隔阂不是必须冲突。若保留解释，倾向只用“两个世界曾受镜路文明连接，语言同源，裴离作为西域使团成员能够基本交流”一笔带过；该细节尚未正式批准。

## 四、用户刚提出的替代路线（未批准）

用户提出：**斯摩奇可能低估阿克塔尔的实力或掌控程度，带着裴离直接去修复核心。**

目前整理出的最小版本如下，但所有细节都仍是提案：

1. 斯摩奇以前已经独自尝试修复核心并失败。它不应忘记阿克塔尔危险；它真正误判的应当是阿克塔尔已经把自己的人员、制度或控制方式嵌入核心到了什么程度。
2. 斯摩奇认为第一次失败主要来自自身严重受损、缺少同源接口。发现裴离的心石后，它相信两者配合能够进入或修复核心的古老层级。
3. 裴离愿意同行，不是为了帮助斯摩奇完成使命，而是因为核心保存着他寻找的源头记录。两人目标暂时重合，却彼此把对方理解成通往目标的条件。
4. 两者跨界后仍可保留一段短途，使裴离见到碎月国真实生活，但不再等待研究院邀请；斯摩奇主动带他接近核心。
5. 行动失败应来自斯摩奇对阿克塔尔控制深度的误判，而不是阿克塔尔提前预知裴离会来。阿克塔尔只能在两者实际接入核心后发现异常。
6. 失败最终可能使斯摩奇被压制后撤、裴离留在核心范围并第一次见到阿克塔尔。但裴离为何留下、是否自愿、斯摩奇为什么无法带他离开，都尚未解决。

这条路线若采用，将正式替换“普通报告—调查人员邀请”的批准路线，而不是与其并存。

## 五、刚刚明确否定或不得偷渡的内容

- 不得让阿克塔尔提前知道裴离想修复老工匠。他在见到裴离前只能知道心石来源与连接事实，不能读取裴离完整人生和目的。
- 不得让研究院刚好拥有一项完全对应老工匠颈背伤势、能恢复手部精细控制的现成技术。用户已明确认为这是为留住主角制造的巧合。
- 不得保证老工匠能够治愈，也不得让阿克塔尔用现成治疗承诺收买裴离。
- 不得把“裴离查到空白心石档案，于是立刻领悟环境、生活和选择塑造了自己”当作已经成立的剧情。用户已否定该展开。
- 不得恢复批量人偶、前代失败品、天选载体、唯一救世钥匙、阿克塔尔全知召回、斯摩奇事先追踪、随机相遇或心石万能翻译。
- 不得让第一次见面直接变成长篇哲学对话，也不得让阿克塔尔靠自述证明自己的秩序有效。
- 不得让裴离一进入碎月国就先被公主或绿洲教育成反阿克塔尔立场。
- 不得给裴离抢走阿月长期修复、维护斯摩奇的作用。
- 不得恢复已撤回的“旧镜站”、唯一关键残片、全国人口档案、系统清剿绿洲或“无身份者一律得不到帮助”等结构。

## 六、本轮必须整体审查的问题

请不要只修补“第一次见阿克塔尔”这一小段。按以下顺序倒查整条因果：

### A. 裴离起源是否成立

1. 阿克塔尔为什么能够判断另一个世界“环境更好”，却又无法持续观察实验结果？这是否需要补充过多跨界能力？
2. 一块空白心石被送出后，如何合理地落入东方老工匠手中并最终成为裴离？目前“西域固定端点—东方工匠”之间仍缺少前史链，这会不会把概率账藏在故事开始之前？
3. 阿克塔尔既然没有预知裴离会回来，裴离回来后成为其理论证明是否仍然有足够人物力量，还是显得作者事后拼接？

### B. 裴离动机是否足够强且不跑题

1. “修复老工匠双手”能否真正支撑离开故乡、跨越世界和长期留在碎月国的风险？
2. 老工匠已经适应新的生活，而裴离执意恢复原状：这是有张力的人物缺点，还是会让裴离显得不尊重养育者、只把人当故障？
3. 这个动机有没有保留裴离的非人感，还是已经变成普通的“为亲人求医”？
4. 它与核心主题的联系是否自然发生在人物行动中，还是只能依靠后期解释“修人对应修社会”？

### C. 西域入场和斯摩奇相遇是否真的摆脱巧合

1. “核心脉冲—西域异象—皇帝派遣—裴离连接—斯摩奇发现”的链条是否因果清楚，还是只是把一次巧合拆成多个步骤？
2. 皇帝为何选择裴离同行、裴离为何能亲自接触端点、使团为什么允许他脱离任务跨界，是否还有未支付的行为成本？
3. 斯摩奇重伤状态下为什么会冒险跨界接触一个未知同源生命？它期待裴离解决什么问题？若答案只是“同源所以可能有用”，是否过弱？
4. 斯摩奇如何确认另一端存在的是生命而非普通部件，又如何在不恢复万能扫描的前提下作出行动？

### D. 两条跨界后路线哪条更适合长篇

请直接比较：

- **路线一：普通报告与自愿邀请。**优点是裴离拥有观察世界和自主权衡的时间；风险是节奏平、人物被动、斯摩奇带他回来后缺少明确行动目的。
- **路线二：主动修复核心并失败。**优点是人物目标推动行动，较快产生危险、分离和国师初见；风险是斯摩奇明知核心危险仍带裴离硬闯可能显得愚蠢，且过快进入核心会挤压异世界落地感。

审查者必须判断哪条更适合，或者明确说明两条都不成立并给出一条新的主路线。新的路线不得依靠新增万能能力、巧合人物、现成治疗或阿克塔尔全知。

### E. 阿克塔尔与裴离初见的逻辑

1. 阿克塔尔在初见前具体知道什么、不知道什么？
2. 他怎样确认裴离就是当年的实验结果，而不是靠读心或作者告知？
3. 他渴望裴离自愿认可自己，这一欲望如何转化成行动，而不是“国师对主角格外宽容”的剧情特权？
4. 他为什么愿意让裴离接触任何资料？什么可以开放，什么绝不会开放？
5. 裴离为什么愿意暂时留下？这个原因怎样来自他原有目标，而不是阿克塔尔刚好给出诱饵？
6. 第一次接触应该产生什么具体变化，才能既有戏剧推动，又不提前完成两人的思想冲突？

### F. 阅读节奏和悬念

1. 从老工匠受伤到西域遗迹、斯摩奇现身、主动跨界、抵达碎月国、第一次见阿克塔尔，信息和转折是否过密？
2. 哪些真相应当在开篇交代，哪些必须延后？
3. 第一卷前段的读者追问应当是什么？这些问题是否逐步升级，而不是一个谜底刚出现就被人物解释掉？
4. 跨界后应该保留多少篇幅观察普通人的生活，才能支撑裴离后来对阿克塔尔的理解，又不使故事失去推动力？

## 七、必须核对的连续性事实

- 在当前时间线中，斯摩奇已经苏醒、尝试修复核心失败，并参与救出公主，之后才跨界接触裴离。任何新路线必须解释它为什么会再次接近核心。
- 公主与阿克塔尔已经是政敌；公主活动依赖分段保密的秘密互助网络。斯摩奇不能随意把裴离“送去公主总部”，也不能假定自己知道所有落脚点。
- 阿月已经参与唤醒斯摩奇，并将长期维护它。裴离可以进行有限检查或尝试，但不能成为取代阿月的修复者。
- 阿克塔尔乐于在必要时动用武力，但他对裴离具有真诚尊重，且需要自愿认可。两点都必须存在，不能只保留其中一个。
- 阿克塔尔不能通过镜子实时看见全国。他的获知必须来自实际连接、已有控制范围、普通报告或可说明的信息链。
- 镜路完整能力分类仍未批准。不得为了修补此段新增远程读心、万能追踪、自由传送、自动翻译、跨界广播等能力。
- 裴离来自异界所需的东方和西域背景应保持最小，不扩展出新的宫廷政治长线。

## 八、期待审查输出

请按以下格式回答，不要写正文和角色台词：

1. **总判断**：当前从裴离起源到初见阿克塔尔的整体结构，属于“基本成立、小修即可”“局部重做”还是“基础逻辑需要重做”。
2. **最成立的三点**：说明为何值得保留。
3. **最严重的三个问题**：按严重程度排序；每个问题指出它影响的前后情节，不能只说“动机不够”“节奏太快”。
4. **对已批准内容的倒查**：逐项判断裴离起源、老工匠动机、西域入场、相遇因果、主动跨界是否保留；如建议撤回，说明最小撤回范围。
5. **跨界后主路线**：在“普通邀请”和“主动修复核心”之间作出判断；若两者都不成立，只给一条新主方案。
6. **阿克塔尔初见边界**：明确他知道什么、不知道什么、为什么不立刻强迫裴离，以及裴离留下的非巧合原因。
7. **主题检查**：说明这些情节是否真的在表现核心命题，还是只给后续哲学讨论搭台。
